# website-pulse
This website uses an API from NASA to load a fun fact with an explanation and picture each day. I used HTML, CSS, JavaScript, Next.js, and Vite using Visual Studio (VS) Code. I made this project for the "Give Your Website a Pulse" mission on Hack Club's Stardance. I added my own CSS styling and completed the unguided challenge to add a conditional for YouTube videos. Additionally, I plan to make the date picker functional to go back to previous days' screens and add my own CSS animation of a black hole to open up the website (or while it is loading). See my project on Stardance at https://stardance.hackclub.com/projects/53562.
